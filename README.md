
# Day 37 - Logistic Regression

## Internship
Veda Technology - AI & ML Track

## Project Description
This project implements a Logistic Regression model for binary classification using Python and Scikit-learn.

## Objective
To build a classification model and understand how it predicts two different classes.

## Dataset
Breast Cancer Dataset from Scikit-learn.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## Steps Performed
1. Loaded the Breast Cancer dataset.
2. Prepared input features and target labels.
3. Split the dataset into training and testing sets.
4. Applied feature scaling.
5. Trained the Logistic Regression model.
6. Predicted test data.
7. Evaluated the model using accuracy, confusion matrix and classification report.

## Results
The Logistic Regression model was trained successfully.
Predictions and evaluation metrics were generated.

## Conclusion
This project helped me understand binary classification, Logistic Regression, model training and evaluation using Scikit-learn.
